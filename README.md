# Medical Equipment Management System

## Description
This is a Django-based Medical Equipment Management System developed for managing medical devices, maintenance, repairs, documents, and inventory within a medical practice.

## Requirements

- Python 3.13
- Django 6.0
- pip

## Installation

1. Create a virtual environment.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Apply the database migrations:

```bash
python manage.py migrate
```

4. Start the application:

```bash
python manage.py runserver
```

## Project Structure

- devices/ - Main application
- medicalsystem/ - Django project settings
- media/ - Uploaded files
- static/ - Static files
